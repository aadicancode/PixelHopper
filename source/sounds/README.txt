SOUNDS DIRECTORY
================

Place your sound effect files here.

Current sound files needed:
- jump.wav (or jump.pda) - Plays when the bunny jumps

Supported formats:
- .pda (Playdate Audio - preferred)
- .wav (WAV format - will be converted automatically)

To add the jump sound:
1. Place your jump.wav file in this directory
2. The game will automatically load and play it when you jump

Future sounds you can add:
- carrot_collect.wav - When collecting carrots
- death.wav - When the bunny dies
- obstacle_warning.wav - When obstacles flash (optional)
